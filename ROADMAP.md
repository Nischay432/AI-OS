# Roadmap

High-level version targets. Task-by-task detail lives in `PHASES.md` — this file is the long view, that one is the actionable one. Shipped versions below are recorded as what actually happened, not what was originally predicted (the v0.1.0 draft of this file guessed differently; see `CHANGELOG.md` for the ground truth).

- **v0.1.0** — ✅ Core + Intelligence foundation.
- **v0.2.0** — ✅ Cross-domain foundations: decisions log (DECISION-001/002/003 incl. game engine) + all three starter templates.
- **v0.3.0** — ✅ AI tool ecosystem evaluated and logged (`reference/tool-evaluations.md`); MCP dev-flow connectors explicitly deferred until a project needs one.
- **v0.4.0** — ✅ Godot starter upgraded to a boot-able project; repo `.gitignore`.
- **v0.5.0** — ✅ Hardening: version semantics (DECISION-004), convention validator + CI, Claude Code-native usage model, `reference/claude-code-guide.md`, template modernization.
- **v1.0.0** — At least one web/app product and one game shipped using AI-OS; `reference/decisions-log.md` has enough entries to show the framework actually holding up over multiple real calls.

No fixed timeline — version bumps happen when the milestone is real, not on a schedule.
